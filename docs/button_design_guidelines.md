# 按钮设计规范（通用版）

适用于桌面端**对话框、消息框、向导**里的标准动作按钮：确定、取消、保存、
不保存、关闭、是、否、应用、完成、上一步、下一步等。

这份文档只讲**原则**，不绑定框架、不绑定本项目的主题 token 或文件路径，
可以直接交给其他项目参照。Qt/PySide6 的现成实现复用说明见第 10 节。

不在本文范围：工具栏图标按钮、分段控件、表格行内 `+/-`、链接按钮、开关 /
复选 / 单选。它们可以有自己的尺寸规范，但状态模型可以沿用本文。

## 1. 目标

1. **外观由产品自己画**，不依赖系统原生按钮，避免 Win10/Win11/macOS 观感漂移；
2. **状态可预期**：常态、悬停、按下、禁用、键盘焦点各自有明确反馈；
3. **平台惯例只影响摆放**：顺序、默认按钮、对齐、宽度策略；
4. **键盘可达**：Enter 有落点、Esc 能取消、Tab 焦点可见；
5. **主题可换**：所有颜色来自主题角色，不在控件代码里写死十六进制；
6. **尺寸稳定**：焦点、按下不改变按钮几何，不引起布局跳动。

## 2. 角色（Role）

| 角色 | 含义 | 典型文案 | 视觉 | 键盘 |
|---|---|---|---|---|
| `accept` | 肯定 / 提交 | 确定、保存、是、应用、完成 | 主色（primary） | Enter |
| `reject` | 取消 / 关闭 / 否定 | 取消、关闭、否 | 普通（neutral） | Esc |
| `other` | 辅助 / 次要动作 | 不保存、重试、帮助、复制报告 | 普通（neutral） | — |
| `destructive`（可选） | 危险动作 | 删除、覆盖 | 危险色（danger） | 不作为默认 |

规则：

- 一排按钮**最多一个 `accept`**；
- 一排按钮**最多一个主色按钮**；没有 `accept` 时不要硬造主色，
  “只有关闭”的整排保持普通样式；
- **默认按钮（Enter 落点）与主色按钮（视觉强调）是两件事**：
  默认按钮可以是 `reject`（例如确认框默认“否”）；是否画成主色要单独标记，
  不要因为它是默认就自动推断；
- 同一产品里同一动作的文案保持一致，不要一处“确定”、一处“确认”。

## 3. 状态模型

| 状态 | 普通按钮 | 主色按钮 | 说明 |
|---|---|---|---|
| 常态 | 表面色 + 强边框 + 主文字 | 主色底 + 主色边 + 反色文字 + 半粗体 | 默认观感 |
| 悬停 | 悬停表面色 | 主色悬停色 | 仅指针设备；禁用态不响应 |
| 按下 | 按下表面色 | 主色按下色 | 鼠标按下 / 空格按住 |
| 禁用 | 禁用表面色 + 弱边框 + 禁用文字 | 同左，**去掉主色** | 不可悬停、不可聚焦 |
| 键盘焦点 | 边框变焦点色 | 边框变反色 | 只改边框，不加内圈 |
| 选中（可选） | 按下表面色 | 主色按下色 | 仅切换型按钮 |

状态优先级：**禁用 > 按下 > 悬停 > 常态**。焦点只覆盖边框颜色，不改变
填充、文字、尺寸。

明确不做的事：

- 不画内侧焦点圆角线框（会像“按钮里又套了一个按钮”）；
- 按下时不位移文字、不缩放按钮；
- 焦点不改变按钮宽高，避免布局抖动。

## 4. 颜色角色

不要在按钮代码里写死颜色。先定义一组语义角色，再由亮/暗主题各自映射：

| 角色 | 用途 | 亮色示例 | 暗色示例 |
|---|---|---|---|
| `surface` | 普通按钮底色 | `#FFFFFF` | `#3D3D3D` |
| `surface-hover` | 悬停底色 | `#F1F5F9` | `#454545` |
| `surface-pressed` | 按下底色 | `#E2E8F0` | `#4D4D4D` |
| `border` | 禁用/弱边框 | `#E5E7EB` | `#4A4A4A` |
| `border-strong` | 普通按钮边框 | `#D1D5DB` | `#5A5A5A` |
| `text` | 普通文字 | `#0F172A` | `#F0F0F0` |
| `text-disabled` | 禁用文字 | `#94A3B8` | `#7A7A7A` |
| `accent` | 主色底 | `#3B82F6` | `#60A5FA` |
| `accent-hover` | 主色悬停 | `#2563EB` | `#93C5FD` |
| `accent-pressed` | 主色按下 | `#1D4ED8` | `#3B82F6` |
| `on-accent` | 主色上的文字/边框 | `#FFFFFF` | `#0F172A` |
| `focus` | 键盘焦点边框 | `#3B82F6` | `#60A5FA` |

规则：

- 主色按钮的**常态边框与底色同色**，焦点时换成 `on-accent`——
  不要用 `focus` 色画主色按钮的边框，两者太接近会看不见；
- 禁用态一律降级到禁用表面色/文字色，**不要保留主色**；
- 文字与底色对比度建议 ≥ 4.5:1；主色上的反色文字同样 ≥ 4.5:1；
- 不要只靠颜色表达状态，按下/悬停应同时有明暗变化。

## 5. 尺寸与排版

推荐值（逻辑像素，按品牌可调）：

| 项目 | 值 |
|---|---|
| 圆角 | 6px |
| 边框 | 1px |
| 内边距 | 上下 5px，左右 14px |
| 内容高度 | `max(文字行高, 图标 16px) + 10px + 2px` |
| 自然宽度 | `文字宽 + 30px`（有图标时 `+ 图标宽 + 6px 间距`） |
| Windows 最小宽 | 84px，或按最长标准文案实测 |
| macOS 宽度 | 按文字自然宽度，不设最小/等宽 |
| 图标 | 16px，与文字间距 6px，垂直居中 |
| 焦点边框 | 仍为 1px，不改变几何 |

补充：

- **Windows 同排等宽**：宽度 = max(最小宽, 当前字体下最长标准文案宽 + 30,
  本排自然宽)。只按本排文字算会让“完成(F)”比“确定/取消”宽一截，建议把
  所有标准文案放进一个候选集合统一量；
- 测量前要确保控件已经套用最终字体（Qt 里先 `ensurePolished()`），
  否则会量到默认字体、比实际窄几像素；
- 长文案（如“1. 选择旧工程文件…”）可以超出统一宽，不要裁字；
- 文本超宽时用省略号，不要压缩字距；
- 助记符：`&` 只用于快捷键，不要画到按钮上；
- 高 DPI：用逻辑像素 + 矢量/抗锯齿绘制，不要预渲染位图。

## 6. 平台规则

| 维度 | Windows（Win32 对话框惯例） | macOS（Apple HIG） |
|---|---|---|
| 顺序 | 肯定按钮在**左**，取消在右 | 取消在左，肯定按钮在**最右** |
| 对齐 | 整行**右对齐** | 整行**右对齐** |
| 宽度 | 同排等宽（≥84px 或按文案实测） | 按文字自然宽度 |
| 默认按钮 | 肯定动作；Enter 触发 | 肯定动作；Enter 触发 |
| Esc | 取消 / 关闭 | 取消 / 关闭 |
| 向导按钮 | 完成/取消同在下排 | 取消在左下、完成在右下 |
| 文案 | 确定 / 取消 / 保存 / 关闭 / 是 / 否 / 不保存 | 同左 |

规则：

- Windows 上不要把肯定按钮放到右边，macOS 上不要放到左边；
- 辅助按钮（“恢复默认”“复制报告”等）放在标准按钮组左侧，标准组靠右；
- 纯 dismiss 的整排（只有一个“关闭”）也要有 Enter 落点，但保持普通样式；
- 平台差异只允许出现在**顺序、默认按钮、宽度策略**上，颜色和状态反馈
  两平台应一致。

## 7. 交互行为

- **悬停**：指针进入变底色；离开恢复；禁用态不响应；
- **按下**：立即变按下色；鼠标移出按钮后释放应取消点击（标准按钮语义）；
- **键盘焦点**：Tab / Shift+Tab / 方向键切换时只变边框颜色；
  **鼠标点击获得焦点不变色**，避免按压瞬间闪线框；
- **Enter**：触发默认按钮；没有 `accept` 时触发显式默认，或最后一个 dismiss；
- **Esc**：触发 `reject`（取消/关闭）；
- **空格**：按下/释放当前焦点按钮；
- **禁用**：不可聚焦、不可点击、不显示悬停/焦点；
- 焦点指示不能改变按钮尺寸或文字位置。

## 8. 反模式

1. **直接用系统原生按钮**：不同系统/版本观感不一致，深色主题容易“文字消失”；
2. **QSS 与自绘同时生效**：两套绘制叠加，出现双层背景/边框；
3. **用 `isDefault()` 决定主色**：Qt 的 `autoDefault` 会把“编辑”“全选”等
   辅助按钮变成默认按钮，从而被误画成主色；
4. **按压时画内侧焦点圆角线框**：像按钮里套了一个按钮，且鼠标点击就出现；
5. **主色按钮用主色画焦点边框**：边框和底色同色，焦点不可见；
6. **固定宽度小于文字宽**：文字被裁或省略，中文尤其明显；
7. **每个弹窗各自算宽度**：向导的“完成”和对话框的“确定”宽一截；
8. **禁用主色按钮仍保留主色**：看起来还能点；
9. **只靠颜色表达状态**：色弱/高对比度场景不可辨；
10. **控件代码里写死十六进制**：换主题要全局搜改；
11. **忘记剥助记符 `&`**：按钮上出现 `&Finish`；
12. **只按 96 DPI 调尺寸**：高 DPI 下文字被裁或发虚。

## 9. 验收清单

- [ ] 所有标准按钮由同一套自绘逻辑绘制，没有系统原生按钮混入；
- [ ] 常态 / 悬停 / 按下 / 禁用 / 键盘焦点五态符合颜色角色；
- [ ] 禁用态去掉主色，且不响应悬停/焦点；
- [ ] 键盘焦点只改边框，没有内圈线框，鼠标按压不出现；
- [ ] Enter 有落点，Esc 能取消；
- [ ] Windows 肯定在左、macOS 肯定在最右；
- [ ] 标准按钮组右对齐，辅助按钮在左；
- [ ] Windows 同排等宽且不小于最小宽；macOS 自然宽度；
- [ ] 向导的完成/取消与普通对话框的确定/取消同宽；
- [ ] 默认字体/DPI 下文字不裁切、不出现 `&`；
- [ ] 亮/暗主题对比度达标；
- [ ] 高 DPI 下边框和文字清晰；
- [ ] 有像素级/布局级回归测试覆盖状态、顺序、宽度。

## 10. Qt / PySide6 复用

**如果是 Qt/PySide6，`button_style.py` 基本可以整份复用**，只需：

1. 替换 `_theme()` 的取色映射（改成你们自己的主题单例/调色板）；
2. 去掉 `_qss_paints()` 里的项目专属 `objectName`（例如 `aiSendBtn`、
   `aiSourceBtn`）；如果你们的 QSS 也用 `role` 标记功能性按钮，保留
   `widget.property("role")` 判断即可。

`platform_buttons.py` 改一下文案和角色定义即可：保留 `DialogButtonSpec`、
`ordered()`、`add_dialog_buttons()`、`apply_standard_widths()` 的结构，
把 `OK_TEXT` / `CANCEL_TEXT` 等换成你们的文案，按需调整 `accept` /
`reject` / `other` 的排序；如果保留等宽规则，把 `_STANDARD_WIDTH_TEXTS`
换成你们的全部标准文案（否则某个按钮可能比同排窄）。

落地步骤：

```python
# 启动时安装（必须在创建窗口之前）
app.setStyle(ButtonStyle(app.style()))
```

```python
# 对话框底部按钮行
row = QHBoxLayout()
add_dialog_buttons(row, [
    DialogButtonSpec("取消", "reject", on_click=dialog.reject),
    DialogButtonSpec("确定", "accept", on_click=dialog.accept),
])
```

Qt 侧的注意点：

- **不要写通用 `QPushButton { background/border }` QSS**：一旦命中，
  Qt 会改走 `QStyleSheetStyle`，`ButtonStyle.drawControl` 就接管不到；
- `ButtonStyle` 只重写 `CE_PushButton` 系列，其它控件仍走底层原生样式；
- `QDialogButtonBox` 的按钮和布局由 Qt 自己创建，不受 `add_dialog_buttons`
  的顺序/宽度规则控制，建议替换；
- `QWizard` 的按钮由 Qt 内部创建：给“完成”标 `primary=True`、其余 `False`，
  并在 `showEvent` 里补一次等宽规则；
- Qt 把 `WA_KeyboardFocusChange` 设在**顶层窗口**上，判断键盘焦点时
  既要看 `State_KeyboardFocusChange`，也要回退读 `widget.window()` 的属性；
- `QStyleOptionButton` 没有 `.font`，用 `widget.font()`；测量前先
  `ensurePolished()`；
- 按钮文本里的 `&` 是助记符，绘制前要剥掉（`&&` 表示字面量 `&`）。

可一并移植的测试：

- 状态像素测试：普通/主色/悬停/按下/禁用/键盘焦点；
- 顺序测试：Windows `accept → other → reject`，macOS 反序；
- 宽度测试：同排等宽、向导与对话框同宽；
- 焦点测试：鼠标焦点不变色、键盘焦点变色、无内圈线框。

## 11. 附：本文取值来源

颜色、圆角、内边距等示例值取自 Section 2.0 的 alpha.2 按钮观感；其他项目
可以按自己的品牌色替换，但建议保留“状态角色 → 颜色角色”的映射方式，
不要把十六进制散落在控件代码里。
