## 背景与目标

图集各表直接给出的值与当前快照/展示不符：图集表里写的是 `D` + `t`（部分表另有 `oD` 列），直径是按 `D±2t` 推的；但构件库快照把 oD/iD/t **三个全存**（`od`/`id` 一组 + `t` 八组），表达式里一律显示 iD/oD 直取、`t=(oD-iD)/2` 反算——对混凝土管这类"图集直接给 iD+t"的管，oD 其实是算出来的却显示成裸数字 730，t 是直取的却显示成公式。

目标（按用户要求）：
1. 每张图集表明确"直接给哪两个"，**快照只存这两个，第三个不存**；
2. 双击构件库插入时**算出第三个、填好再入项目**；
3. 计算表达式窗体"基本参数"页**标注哪两个是图集直取、哪个是反算**。

## 直取对映射（核心依据）

由 `AtlasCatalog.read` 现有分支（`src/app/services/atlas.py:294-309`）+ `d_kind`（`atlas.py:46-58`）+ 各表有无 oD 列（`docs/管道图集直径数据梳理.md`）：

| 图集表 | 直取 | 反算 |
|---|---|---|
| 砼管砼/砂基础(表0/1)、砼顶管(2)、HDPE缠绕(3)（D=内径、无oD列） | **iD + t** | oD = iD+2t |
| PE给水管(4)、PVC-U/PE 非加筋缠绕行(5/6)、钢带PE(7)、球墨铸铁(8)、钢管(9)（有oD列或D=外径） | **oD + t** | iD = oD−2t |
| PVC-U 加筋、PE 缠绕行（有oD列且D=内径，结构壁不在t里） | **oD + iD** | t = (oD−iD)/2 |

标记值：`"id_t"` / `"od_t"` / `"od_id"`；`""` = 未知（旧数据/无图集行），维持现状显示。
