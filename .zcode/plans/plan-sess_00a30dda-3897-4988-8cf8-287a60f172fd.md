# 完全复刻原版"原则"UI 与左栏交互

## 复刻依据
原版 C# 源码在仓库只读参考区 `section/section1.2.2.171220_beta/section/`(FormMdi/panelPrincple、FmPcp/FormPE、FormPF、FormUnit 等),界面坐标、列头、菜单文案、交互逻辑全部照抄;构件库数据直接复用原版 `bin/Debug/Inventory/EleInventory.stn`(5 类别 380 个元素模板,与工程 .stn 同为 XML 格式,现有 `parse_legacy` 可直接解析)。

## 总体布局决策
- 保持开发计划已定的**单窗体模式**(不做 MDI 多窗体):原则横条放在中部工作区正上方(对应原版 panelPrincple 位于 MDI 区上方),未打开工程时隐藏(原版行为)。
- 中央工作区**移除"原则"页签**,原则编辑全部改为**模态对话框**(原版交互:双击原则标签打开);工作区只剩 单位工程/汇总 两页。
- 左树**去掉"围护原则/地基处理原则"分组节点**(原版树只有 项目→标段→单位工程;原则全在横条管理)。

## 任务清单

### 1. 原则横条(新文件 `app/views/panels/principle_bar.py`)
照抄 FormMdi `panelPrincple`:横条内从左到右 = [↑][↓] 竖排小按钮 + 竖分隔线 + 单选组「沟槽围护/地基处理」(默认沟槽围护) + 原则标签横排区(可横向滚动) + [+] 按钮。
- 标签:200×40、白字居中、微软雅黑加粗 14pt;围护底色 `#448AFF`,地基底色 `#455A64`(原版色值)。无选中高亮(原版没有)。
- ↑/↓:移动项目树当前选中的标段/单位工程节点(复用 `project_vm.move`;根/未选中时无效)。
- 单选切换:在围护/地基两组标签间切换显示(原版 RBmPE/RBmPF)。
- [+]:按当前单选新建原则,默认名「新围护原则/新地基原则」,重名自动加数字后缀(原版 ReNameToAdd),不弹输入框。
- 双击标签 → 打开对应 FormPE/FormPF 复刻对话框(见 3/4)。
- 右键标签 → 菜单(原文):`编辑原则`/`导入原则`/`导出原则`/`删除原则`/—/`添加沟槽围护原则`/`添加地基处理原则`。
- 删除原则 = 原版语义:只剩 1 条时弹「至少需要一种沟槽围护原则。」;否则确认「删除后该原则的引用将被<另一原则名>替代,确认删除?」,确认后把所有 Element 引用改指向另一条(新版单原则引用,无比例可并),再刷新。
- 数据源 `project_io.enclosures()/foundations()`,订阅 `project_opened/project_closed/tree_structure_changed` 重建标签。

### 2. 数据层(`app/services/project_io.py`、`app/orm/models.py`、`app/orm/base.py`)
- 新增重名自动后缀 helper,`create_enclosure/create_foundation` 接入。
- `delete_enclosure/delete_foundation` 改为上述"并入另一原则"语义(替换现在"被引用即禁止"的检查)。
- 新增 *.spcp 单原则导入/导出(原版 XML 格式,根元素 `mcPcpEnclosure`/`mcPcpFoundation`,字段标签与旧版 toXML 一致,样例见 EleInventory.stn 的 mcPcpEnclosure 节点)。

### 3. FormPE 复刻对话框(`app/views/dialogs/enclosure_edit_dialog.py`,816×581 可调)
布局照抄 FormPE:顶部「原则名称:」;GroupBox「挖填类型」(开挖类型 7 项下拉/坞塝材质/坞塝回填 4 项下拉(至管顶50cm…)/顶部回填,含原版 坞塝回填选项↔dock_l/dock_h/cover50/cover 双向映射);GroupBox「管道基础」(采用/不采用混凝土基础、角度 90/120/150/180、垫层材质+厚度);GroupBox「降水措施」(描述 Label + 「编辑降水措施原则」「编辑工作面宽度原则」两按钮);右侧竖排「确认修改/取消修改」;主表格 6 列 `埋深/范围(只读,末行+∞)/围护类型(库 Ei+"多级围护"下拉)/围护形式描述(只读)/止水类型(WSi)/止水形式描述(只读)` + [+]。

- "编辑副本、确认生效":打开时读入内存副本,仅「确认修改」写库提交并广播刷新,「取消修改」丢弃。

- TreePanel 改为垂直 QSplitter:上半=项目树(现状),下半=构件库面板(新增)。
- 上半按原版:树结构去掉原则分组节点(`project_vm.build_tree` 与相关路由同步调整);右键菜单文案/结构照原版——根:`项目汇总`/`添加标段`;标段:`标段汇总`/`添加标段`/`添加单位工程`/`删除标段`;单位工程:`单位工程汇总`/`添加标段`/`添加单位工程`/`删除单位工程`(汇总项→切到汇总页签)。保留新版已有的删除确认与 F2 行内重命名(比原版安全,不影响布局)。
